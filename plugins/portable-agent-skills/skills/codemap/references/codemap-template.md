# CODEMAP template

Use this file as the current structural index for a repository. Verify entries against source whenever
they affect a decision or change.

## System boundaries

| Area | Owner | Inputs | Outputs | Entry points | Persistent state | Consumers |
|---|---|---|---|---|---|---|

## Dependency edges

| Producer | Artifact or interface | Consumer | Contract | Verification |
|---|---|---|---|---|

## Shared schemas and state

| Schema or state | Writer | Readers | Compatibility rule | Migration check |
|---|---|---|---|---|

## Path assumptions

| Path or location | Owner | Dependents | Resolution rule | Relocation check |
|---|---|---|---|---|

## Maintenance rule

Update this map when ownership, imports, entry points, producer-consumer edges, shared schemas, or
persistent-state locations change. Keep chronology and superseded decisions in the project's history,
not in this current-state index.
